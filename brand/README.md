Web runtime copies live under `web/img/` (favicon sizes + mark).

## GitHub avatar

`gh` is not authenticated in this environment. Upload `brand/github-avatar.png` manually:

1. GitHub → profile or org **Settings → Profile → Profile picture**
2. Or repo **Settings → General → Social preview** (optional square crop of the same mark)
